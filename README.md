# Hot Memory

Convert Rekordbox memory cues to hot cues.

## Purpose

Rekordbox memory cues are great for marking important sections of tracks, but hot cues offer faster access during performances. This tool helps you pack, test, and implement memory cues as hot cues.

## Features

- Parse memory cue data
- Convert to hot cue format
- Export for Rekordbox compatibility
